# VerPoli – Begleitmaterialien

Dieses Repository enthält die Begleitmaterialien zur 3. Auflage von

**Detlef Jahn & Sophie Suda, _Einführung in die Vergleichende Politikwissenschaft_, Springer VS.**

Die Materialien umfassen Datensätze sowie Stata- und R-Syntaxen zur Replikation der im Lehrbuch verwendeten empirischen Beispiele und Abbildungen.

## Webseite

Die Begleitmaterialien sind über die folgende Webseite zugänglich:

**https://verpoli-materialien.github.io/**

## Inhalt

Das Repository enthält:

- `daten/` – für das Lehrbuch aufbereitete Datensätze
- `stata/` – Stata-Syntaxen (`.do`)
- `r/` – R-Skripte (`.R`)
- `index.html` – Quellcode der Webseite

Weitere im Lehrbuch verwendete Datensätze werden auf der Webseite verlinkt und können von den jeweiligen Originalquellen bezogen werden.
